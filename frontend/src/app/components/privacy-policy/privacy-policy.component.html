Privacy Policy

Updated: June 20, 2026


Use a self-hosted qbit explorer

For maximum privacy, run your own qbit explorer and connect it to your own qbit node and qbit-electrs instance. A self-hosted explorer keeps your lookups, browsing patterns, and node dependencies under your control.


By accessing this website, you agree to the following Privacy Policy:

Data handled by this website

This qbit explorer does not require accounts, subscriptions, payments, third-party trackers, or third-party cookies. The application stores only local browser preferences such as language, theme, graph window, mining window, timezone, and display units.

The operator of this instance may collect basic webserver logs for operational security and debugging. Those logs can include your IP address, request path, user agent, and request time. Retention and access controls are the responsibility of the operator of this instance.


Disabled services

This qbit fork disables optional paid, account, and externally hosted services by default. Transaction lookup, address lookup, block data, fee estimates, and mining data should be served by the configured qbit backend and qbit-electrs service for this instance.


Verification

Explorer data is informational. You should verify balances, transactions, and consensus state with software you control before relying on them for financial decisions.
